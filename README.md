# C3.SYS Website

A modern React website for an independent electronic music label, built with Vite and TypeScript.

## Features

- **Audio Player**: Global audio context with playlist management
- **Artist Profiles**: Detailed artist pages with releases and tracks
- **Release Catalog**: Album/EP showcase with multiple formats
- **Responsive Design**: Mobile-first approach with modern UI
- **Music Discovery**: Featured content and track exploration

## Tech Stack

- **React 18** with TypeScript
- **Vite** for fast development and building
- **Tailwind CSS** for styling
- **Shadcn/ui** for UI components
- **Radix UI** for accessible primitives

## Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd c3sys
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The site will be available at `http://localhost:3000`

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production (Vite only)
- `npm run build:check` - Build with TypeScript checking
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

### Building for Production

```bash
npm run build
```

This will create a `dist` folder with the production build that can be deployed to any static hosting service.

### Development Notes

- The development server runs on port 3000 by default
- Hot module replacement is enabled for fast development
- Some UI components were generated by Figma Make and may have residual version-specific imports
- TypeScript strict checking is relaxed for smoother development experience
